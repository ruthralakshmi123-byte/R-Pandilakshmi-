 # Live Revenue Pulse Dashboard

This project is a real-time sales dashboard built using Python and Streamlit.

It simulates live sales data every 30 seconds and shows:
- Total Revenue
- Current Order Volume
- Sales by City
- Sales Over Time
- Live Weather by City
- Weather Impact on Sales

## Project Files

- `live_dashboard.py` → Main Streamlit dashboard file
- `requirements.txt` → Required Python packages

## Features

- Auto-refreshing live dashboard
- Fake sales data generation
- SQLite database storage
- Live weather integration using Open-Meteo API
- Command center style user interface

## Installation

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

## Run the App

```bash
python -m streamlit run live_dashboard.py
```

## Deployment Steps

1. Create a new repository in GitHub.
2. Upload `live_dashboard.py` and `requirements.txt`.
3. Open Streamlit Community Cloud.
4. Click **Deploy an app**.
5. Select repository, branch, and `live_dashboard.py`.
6. Click **Deploy**.
7. Share the generated app link.

## Output

After running the app, you will get a live dashboard in the browser with auto-refreshing sales and weather updates.
